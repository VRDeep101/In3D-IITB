# BiduKo Studio — Cinematic 3D Architectural Experience

A full-screen interactive Three.js architectural experience featuring a supplied GLB model, animated camera views, structure inspection, atmospheric lighting, reflective water, and snowfall.

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

The supplied architectural model and font assets are kept in `public/`.
